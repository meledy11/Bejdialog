没 有 méiyǒu без / не имея

⚠️ В китайском нет предлога «без» — вместо него 没有 (не иметь)
✓
我不能没有你
Wǒ bù néng méiyǒu nǐ
Я не могу без тебя
没有 = не иметь → «без»
✓
没有糖的咖啡
Méiyǒu táng de kāfēi
Кофе без сахара
没有 = не имеет сахара → без
✓
他没有钱就走了
Tā méiyǒu qián jiù zǒu le
Он ушёл без денег
没有钱 = без денег
✓
没有你很无聊
Méiyǒu nǐ hěn wúliáo
Без тебя скучно
没有 = «не имея тебя»
✓
没有你我很难受
Méiyǒu nǐ wǒ hěn nánshòu
Без тебя мне плохо
难受 = тяжело, плохо (не «грустно»)
✓
没有他我不知道怎么办
Méiyǒu tā wǒ bù zhīdào zěnme bàn
Без него я не знаю, что делать
怎么办 = что делать
✓
没有你的日子很难过
Méiyǒu nǐ de rìzi hěn nánguò
Без тебя дни тянутся долго
没有…的 = без (чего-то)
✓
没有水不能活
Méiyǒu shuǐ bù néng huó
Без воды не прожить
没有水 = не имея воды
✓
没有手机我不行
Méiyǒu shǒujī wǒ bù xíng
Без телефона я никак
不行 = никак, не справлюсь
✓
没有钱什么都做不了
Méiyǒu qián shénme dōu zuò bù liǎo
Без денег ничего не сделать
什么都 = ничего · 做不了 = не сделать
✓
没有你的帮助我做不到
Méiyǒu nǐ de bāngzhù wǒ zuò bù dào
Без тебя я не справлюсь
帮助 = помощь · 做不到 = не справиться
✓
没有他我们不行
Méiyǒu tā wǒmen bù xíng
Без него мы никак
不行 = не получится / никак
✓
没有太阳就没有生命
Méiyǒu tàiyáng jiù méiyǒu shēngmìng
Без солнца нет жизни
没有…就没有… = без… нет…
✓
没有朋友很孤单
Méiyǒu péngyǒu hěn gūdān
Без друзей одиноко
没有 = «без» в китайском
✓
没有你的支持我坚持不了
Méiyǒu nǐ de zhīchí wǒ jiānchí bù liǎo
Без твоей поддержки я не выдержу
没有…的 = без (чего-то)
✓
没有咖啡我没精神
Méiyǒu kāfēi wǒ méi jīngshén
Без кофе я никакой
没精神 = без сил, вялый
✓
没有你我不去
Méiyǒu nǐ wǒ bù qù
Без тебя я не пойду
不去 = не пойду · 没有你 = без тебя
✓
没有爱活着没意思
Méiyǒu ài huózhe méi yìsi
Без любви жизнь пустая
活着 = жить · 没意思 = пусто, без смысла
